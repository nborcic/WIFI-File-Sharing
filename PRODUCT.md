# Product

## Register

product

## Users

People sharing files between a computer and phone on the same trusted Wi-Fi network. They are usually standing near both devices and want to move files without accounts, cables, or cloud storage.

## Product Purpose

WIFI File Sharing provides a local web page for uploading files from one device and downloading them from another. Success means the user can quickly identify the correct phone URL, choose files, upload them, and download shared files with minimal explanation.

## Brand Personality

Practical, clear, restrained.

## Anti-references

Avoid marketing landing pages, decorative dashboards, dark terminal themes, oversized heroes, novelty controls, and visual effects that slow down a simple file-transfer task.

## Design Principles

- Put the transfer workflow first.
- Make phone access obvious.
- Use familiar controls with large touch targets.
- Surface risk clearly because everyone on the local network can access shared files.
- Keep the interface calm enough for repeated utility use.

## Accessibility & Inclusion

Target WCAG AA contrast, keyboard-accessible controls, visible focus states, mobile touch targets, reduced-motion-safe transitions, and copy that works for non-technical users.
